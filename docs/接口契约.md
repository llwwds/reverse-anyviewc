# AnyViewC 接口契约

> 逆向自前端 bundle，并用 CDP 抓真实请求逐条核对过。
> 平台改版后本文件即失效，重新发现的流程见 [SOP-无浏览器.md](SOP-无浏览器.md) §5。

---

## 1. 网关与鉴权

| 项 | 值 |
|---|---|
| 网关前缀 | `https://anyview.gdut.edu.cn/api` |
| 服务前缀 | `user-service` / `scheme-service` / `exam-service` / `gdb-service` |
| 鉴权头 | `token: <JWT>` |
| 会话模型 | **单点登录**：同一账号重复登录会让旧 token 立即失效（`403 当前用户状态失效`） |

## 2. 读接口

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/user-service/rsa` | 取登录公钥（裸 base64 DER/SPKI，需自行补 PEM 头尾） |
| `GET` | `/user-service/school/listAll` | 学校列表（用于取 `schoolId`） |
| `POST` | `/user-service/login` | 登录，form-urlencoded |
| `GET` | `/scheme-service/scheme/list/student` | 当前账号的课程 / 作业表列表 |
| `GET` | `/scheme-service/catalog/list?schemeId=&classId=` | 某课程下的题目目录 |
| `GET` | `/scheme-service/scheme/list/student/{eid}` | 单题详情：题干、`stuCode`(base64)、`kind`、`language`、`questionFullName` |
| `GET` | `/scheme-service/scheme/list/student/detail/{eid}` | 判题状态：`exerciseStatus` / `firstPastTime` / `cmpCount` … |

登录密码加密方式：`RSA/PKCS1v15`，明文为 `password + "," + 毫秒时间戳`，公钥接口返回的裸 base64 DER 需包成 PEM。

## 3. 写接口（三个，三套 Content-Type）

**这是本项目最容易踩错的地方**：Content-Type 弄错时网关回的是 `404 {"path":...}` 而不是 `415`。看到 404 先怀疑自己的请求格式。

### 3.1 保存代码

```
POST /api/gdb-service/exercise/saveStudentCode
Content-Type: application/json

{"eID": "<eid>", "studentCode": "<base64 源码>"}
```

### 3.2 编译比对

```
POST /api/gdb-service/code/compile
Content-Type: application/x-www-form-urlencoded

eID=<eid>
stuCode=<base64 源码>
isTeacher=false
isDebug=false
questionRes.questionFullName=<长名，形如 第1章-DC01PE03e>
```

注意 part 名是 **`questionRes.questionFullName`**（带点），值用**长名**。

### 3.3 运行判题

```
POST /api/gdb-service/code/runGroup
Content-Type: multipart/form-data
Header: Eid: <eid>

questionFullName=<短名，形如 DC01PE03e>
eID=<eid>
isTeacher=false
kind=<3>
language=<1>
stuCode=<base64 源码>
```

注意 part 名是 **`questionFullName`**（不带前缀），值用**短名**。与 3.2 正好相反。

**这是唯一会把 `exerciseStatus` 置为 2 的接口。** 前端没有「标记通过」这种独立接口，工具栏也没有「提交」按钮 —— 只有编译(F5) / 运行(F7) / 调试(F8) / 保存(Ctrl+S)。所以「运行」即「提交」。

## 4. 响应判据

```json
{"code": 200, "data": {"passed": true, "errorOrder": {}, "end": true, "runRightCount": 6}}
```

- `passed: true` → 判题通过
- `errorOrder` 非空 → 列出未通过的数据组
- 状态查询里 `exerciseStatus`：`0` 未做 / `1` 已作答 / `2` 已通过

## 5. 已知坑

| 坑 | 现象 | 处置 |
|---|---|---|
| Content-Type 不匹配 | `404 {"path":...}` | 对照 §3 逐个核对 |
| 保存异步落库 | 代码正确却 `passed=false` | `save → 等 6s → compile → 等 2s → run`，失败再等 8s 补判 |
| 16 位整型环境 | `MAXINT = 32767` 而非 2147483647 | 用平台给的 `MAXINT` 宏，别写 `INT_MAX` |
| `allinclude.h` 自带类型 | 重复 typedef 报错 | 平台已定义 `ElemType` / `KeyType` / `SqStack` 等，不要再定义 |
| 无 `OVERFLOW` 宏 | 编译报未声明标识符 | 溢出场景直接 `return ERROR` |
| 单点登录互踢 | `403 当前用户状态失效` | 同一时刻只保留一个会话，重跑 `login.py` |
| WAF TLS 指纹 | `requests` 被拦成 403 或挑战页 | 走 curl；备选 urllib；详见 SOP §6 |
| `accumTime` 不可写 | 耗时恒为 0 | 该字段只由 WebSocket 连接时长累加，无 HTTP 接口可写 |
| 把平台当前 `stuCode` 当模板 | 第二次提交必 `redefinition` / `conflicting declaration` | 提交一次后平台模板就是你的代码；拼装要用首次抓取的原始模板，前置片段按符号去重 |
| 自己声明平台提供的函数 | `undefined reference to ...`（不是编译错） | 题目写「可以直接调用」的，连原型都别写，按值/按引用写法不一致会链到不存在的符号 |
| 链队列按「带头结点」写 | `Queue=(D)` 判成空、长度少 1 | 这套 `LQueue` 不带头结点：`front` 指向首个元素，空时 `NULL` |
| 循环队列 `rear` 语义 | 出入队内容整体错位 | `rear` 指示队尾元素位置；表长 `MAXQSIZE`，判满用 `length >= MAXQSIZE` |
| 广义表层次起点 | 输出 `A0` 而标准是 `A1` | 平台传 `layer=0`，但标准输出把最外层原子记作第 1 层，输出与递归都要 `+1` |
| 「链表不存在」当成异常 | 该题判错而其他用例正常 | 这是合法输入：复制/去重类返回 `NULL`，合法性判定类返回 `TRUE`，逐题看标准输出 |

## 6. 一个反直觉点

`scheme/list/student` 返回的 `code` 是 **31**，不是 200。这是正常业务码，`data` 里有完整数据。别把它当错误 —— 判错会导致抓到空列表。
